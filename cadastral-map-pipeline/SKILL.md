# 地籍出圖端到端工作流（清冊 → 成果圖）

把三支子 skill 依序串成一條產線。**本 skill 只做統籌與交接**,每一段的細節在各子 skill。
遇到該段就呼叫該子 skill,不要在這裡重造流程。

## ⚠️ 執行紀律(所有模型適用;Opus/Sonnet 接手時尤其不可違反)

1. **硬閘門必過**:每段交接跑 `scripts/pipeline_check.py` 對應子命令(下方各段標註),
   **exit≠0 就照訊息處置;處置不了→停下回報使用者,禁止繞過或憑感覺續跑**。
2. **瀏覽器操作用現成 driver,不要重寫**:批次選取=tcdgis `scripts/batch_driver.js`、
   收尾下載=`scripts/finalize_download.js`(注入→輪詢狀態即可)。driver 內的節流/重試/
   取消規則是實測傷痕,**嚴禁「優化」**(例:縮短 10.5s 節流、對「查無地號」重試、
   多按一次「確定」)。
3. **遇到 skill 未記載的平台行為**(新彈窗、新元件、新錯誤訊息)→ 截圖+記錄現象,
   **停下回報,不要即興修復**。新版式清冊/平台改版的首跑交給高階模型。
4. **數字只能來自實算**:任何要交付的數量/面積,必須能指出來源腳本輸出;對不上=停。
5. 唯二允許自行重試:WMTS 逾時(make_maps 內建)、平台限流訊息(driver 內建一次)。
6. **農業用地變更案一律補做 Ⓒ 隔離綠帶或設施工項**(2026-08-02 使用者定案)——基地是
   農業用地(要點§2② 六類)且要變更作其他使用者,不論走容許使用／變更編定／開發許可／
   都計變更,**都要跑 Ⓒ 並在簡報出「綠帶劃設」與「面積計算式」兩頁**;不要等使用者問。

```

  │     → scripts/cadastre_fetch.py fetch；可先跑 ②b/Ⓐ/Ⓒ 看有無 ╳ 級障礙
  │  ⓪ parcel-roster-verify         地號健檢（★需你本人登入,與①同一次登入）

  │  ② shp-xls-area-join            本機腳本（--trust-fields）
  ▼     帶屬性基地 shp（地號/使分/使類/所有權人…）
  │  ②b build_sites_sitemap         案場定義（多案場必做）→ 權威 sitemap（帶段欄）
  ▼  Ⓐ check_zones                  ★第0步：法定禁止／不同意事由（YAML 驅動）
  │                                 禁止事由檢核.txt/.json；有 ╳ 級先解決才往下
  │  ②c road_access                 臨路評估（產線內建,不再相依 fishpv）
  │                                 成果.xlsx / sites.shp / features.geojson
  │  Ⓑ persite_stats                逐案場統計（簡報數字唯一來源）
  ▼  Ⓒ 隔離綠帶或設施 ★農業用地變更案必做（見下方專節；四支腳本一條龍）

  │     ＋ make_extra_maps --theme 隔離綠帶
  │     綠帶計算.txt/.json、隔離設施.shp／隔離綠帶.shp、隔離綠帶計算式.csv、綠帶計算式.png
  │  ③ make_maps --layout maxmap    QGIS（沿用 parcel-map-sheet 版面）
  ▼     圖檔_maxmap/ 六主題 A4 成果圖 ＋ 05_出圖清單_maxmap

  ▼     001_<案>_環境敏感.png ＋ 環境敏感套疊_逐類面積.csv
  │  ③d make_extra_maps            補充主題圖（權屬／環域／養殖漁業生產區／

  ▼     使用者可在 QGIS 開啟修編任一張圖再匯出
  │  ④ parcel-briefing-deck         簡報產製（頁數依案情；變更編定案加綠帶計算式頁）
```

## 需要人工/環境的兩個點（先講清楚,不要假裝全自動）

- **①的登入**:`ngis.nlma.gov.tw` 帳密＋圖形驗證碼**由使用者本人輸入**(安全規則:agent
  不可代填、不可解驗證碼)。開好登入頁請使用者完成,回覆「好了」再續。
- **③的環境**:出圖須用 **QGIS 內建 python**(`python-qgis-ltr.bat`);正射套疊/國土利用
  需連 NLSC WMTS(未快取時)、臨路判定需 ②c 臨路評估產物。缺資料的主題單張標失敗續跑。

其餘全自動。

## 逐段交接

### ⓪a 免登入先跑一輪 → 用 `cadastre-check`(★2026-08-02 納入產線)

**先跑這步，再決定要不要／何時佔用平台登入。** 走農業部地籍圖資＋內政部 getLandInfo，
**免帳號、免驗證碼、無 10.5 秒節流**。

```powershell
# 基地
python -X utf8 scripts\cadastre_fetch.py fetch --county <縣市> --town <鄉鎮> `
    --section <段名含小段> --landnos <地號...> --out <案>\cadastre --name 基地
# 鄰地（綠帶應留設側判定用）
python -X utf8 scripts\cadastre_fetch.py fetch ... --landnos <鄰地地號...> --name 鄰地
```

**能拿到什麼（布袋306 七筆逐項對帳，2026-08-02）**：

| 項目 | 對帳結果 |
|---|---|
| 幾何 | **與 TCDGIS 官方 shp 完全相同**——IoU 100.00%、面積差 0.00 ㎡、質心位移 0.00 m、頂點同為 22；七筆圖面積全部等於平台向量面積（差 <0.01 ㎡） |
| 登記面積 | ＝ 平台標示面積（306 2,500.00／306-1 4,897.97 完全一致） |
| 使用分區／使用地類別 | **7/7 完全一致** ← 綠帶應留設側判定所需，這裡就夠 |
| 公告現值／地價 | 有 |
| 重測改號 | **自動追蹤**（走內政部新舊地號對照，不可採信農業部模糊比對回的那筆） |
| 版次回溯 | 可指定舊版次，能重現分割前狀態 → 抓近年有異動的鄰地 |

**⚠ 三件事它拿不到，仍必須上 TCDGIS**：

1. **公私別／所有權人／管理者**——`getLandInfo` 回傳 20 個欄位裡沒有（已實測列舉確認）。
   因應手段完全取決於權屬（西港案：國有水利地買不到，只能申請搭版橋）→
   **不可用 ⓪a 的成果推論權屬**。
2. **環境敏感地區套疊分析 53 項**——只有平台有（①b）。
3. **離島（澎湖／金門／連江）幾何**——農業部服務無資料，段清單完整但界址環一律回空。

**所以正確的分工**：⓪a 免登入把幾何、使分使類、鄰地應留設側、禁止事由檢核先跑完；
**TCDGIS 那次登入縮到只為「權屬＋環敏」而跑**。原本 ⓪＋① 要本人守著 20 分鐘，
現在可以先無人值守跑完判定，登入只做兩件事。

**幾何權威**：送審交付仍以平台官方 shp 為準（使用者 2026-07-15 鐵律）。要把 ⓪a 升為
主來源需累積逐案證據——每案跑一次對帳，把結果記進 STATE.md：

```powershell
python -X utf8 scripts\cadastre_fetch.py verify --cad <案>\cadastre\基地.shp `
    --official <案>\joined\<案>_面積join.shp
```
IoU ≥99.9% 且面積差 ≤0.1% 才回報通過；有實質差異一律以平台為準。

**三個誤讀要避免**：

1. `MISMATCH` **不等於「該地不存在」**，正解是「此地號在該版次不存在（可能已分割或
   段名變更）」——那支 API 查不到時會回別筆地甚至跨縣市，是 14 碼閘門擋下來的。
2. `圖面積 vs 登記面積` 的偏差（實測 391 地號 +11.15%）是**官方資料本身**在圖解區的常態
   （平台向量面積同為 1,366.02），不是這支管線的誤差，**面積一律用登記值**。
3. **地號母號 ≥9000 ＝ 未登記土地**（2026-08-02 使用者告知並實證）：地政為製作圖資給了
   地號但**無登記屬性**，回 `OK`＋有幾何＋`registry=None`，是正常結果。嘉義縣快照 11,377 筆
   全部 使分/使類 空白、登面積 0.0。**此時面積只能用圖面積**；綠帶留設側判定它不屬
   要點§2② 六類農業用地 → 該側免留設（引擎因 使類 空而自動歸非應留設側，行為正確）。
   ⚠ **空白使類不可推論為都市土地**——母號<9000 的空白（快照 29.6%）才是都市土地，
   兩者處置不同。`cadastre_fetch.py` 已加 `未登記` 欄自動區分。

### ⓪ 清冊地號健檢 → 用 `parcel-roster-verify`(新清冊一律先跑)
清冊逐段批次加入 TCDGIS 多重地籍選取=平台即時驗證每筆地號;「查無地號」不重試,
走 MOI 新舊地號 API(免認證)換算現行段/地號後補加入並回填清冊(原檔備份+備註依據)。
**交接約定**:⓪跑完平台清單已含全部(修正後)地號且已全範圍定位——**同一 session 直接
接①的加入主題→下載 shp 與匯出 Excel,不要登出重來**(前端清單跳轉即失)。
陷阱備忘:重測後相近段名同號≠同宗地,禁止在相近段名直接試同號(詳該 skill)。

### ① 取官方地籍 → 用 `tcdgis-parcels-to-shp`(⚠️ 一律走這步,無例外)
**使用者鐵律(2026-07-15):任何案子(含清冊模式/多案場批次)基地幾何一律上平台登入
下載「最新」官方 shp。** 不可改走 `大量圖資轉換工具` 舊手冊的本機地籍比對
(match_parcels)取幾何——本機 `地籍圖資/` 是舊快照,僅供③擷取周邊地籍/功能分區。
多案場清冊:選取分組=(縣市/鄉鎮/段/小段),下載後建**段+地號複合鍵** sitemap
(跨縣市清冊同地號會跨案場,純地號鍵會分錯家;`load_sitemap` 支援 段/小段 欄)。
**⚠️ sitemap 必含「段」欄(2026-07-16 東石實錯)**:同一鄉鎮跨段重複地號(魚塭區常見)
會讓 load_sitemap 移除衝突純地號鍵;csv 無段欄=複合鍵建不出→該地號分派失敗,
單筆案場會**整案無聲消失**(引擎只緩衝一句警告,05 清單看不到)。清冊無分基地欄時
一律走 ②b 的 `build_sites_sitemap.py`(產出即帶段欄);歷史案的無段欄 sitemap 可用
`rebuild_sitemap_spatial.py` 以既有 sites.shp 為權威補救。**sitemap 閘門必須驗「實際
餵給 make_maps 的那一份檔案」**——驗過≠餵入的那份(東石事故:後置步驟覆寫了驗過的檔)。
多重地籍選取(=`batch_driver.js`)→ 收尾(=`finalize_download.js`:定位→匯Excel→建主題
→加入一次→下載)。
**交接約定**:把下載的 zip 與匯出的 Excel **存成同一個 basename**(下一段靠同檔名自動配對)。
**🚧 閘門**:`pipeline_check.py geometry <解壓後shp> --expect <清單筆數>`(抓重複插入/筆數不符)。

**都市計畫區/國家公園區回「查無」是正常**,非錯誤;版本是**報部版草案**,交付口徑需寫「以縣市政府認定為準」。
向量面拿不到(平台擋),面圖層仍走本機 `國土功能分區/` 圖資。

### ② 屬性接回 → 用 `shp-xls-area-join`


### ②b 案場定義(多案場清冊必做;2026-07-16 定案)
**案場定義權在產線。** 由聚類直接產帶段欄的權威 sitemap,臨路評估依該分組計算——
案場幾何與 make_maps 出圖用的完全一致,根除「聚類真相在外部工具、產線拿到失真副本」
(東石 S012 整案消失的結構性根因)。

- 清冊**有**分基地欄(如清潔隊):照舊從清冊建帶段欄 sitemap。
- 清冊**無**分基地欄(如東石,一份清冊=一堆相鄰宗地群):
  ```powershell
  python scripts\build_sites_sitemap.py --joined <②joined.shp> --out-dir <案>\案場定義
  ```
  相鄰宗地連通分量聚類(--gap 預設 0=須相鄰),產 `案場定義/sitemap.csv`(帶段欄)+
  `sites.shp`;編號北→南確定性(重跑不變),`--match-sites` 可沿用歷史編號。
- **先過 sitemap 閘門**(對 案場定義/sitemap.csv),再算臨路(見下方 ②c)。
- run_case 的 digest 會**優先複製 案場定義/sitemap.csv** 給出圖;無案場定義且成果.xlsx
  反推出跨案場重複地號時會硬停並指路本步驟(不再無聲寫出無段欄 sitemap)。
- run_case 的 `roadaccess` 步驟會在 sitemap 不存在時**自動先跑** build_sites_sitemap,
  故一般走 run_case 不必手動執行本步。

### ②c 臨路評估(產線內建;2026-07-26 起不再相依外部 fishpv)
```powershell
& "<QGIS>\bin\python-qgis-ltr.bat" scripts\road_access.py --joined <joined.shp> `
    --sitemap <案>\案場定義\sitemap.csv --out <案>\臨路評估
```
國土利用 LUIMAP 圖磚 → 最近色分類向量化 → 逐宗基地**臨路三態**(直接臨路≤0.5m/
需搭橋臨路≤1.5m/不臨路;一般道路與防汛道路分別評估)＋地形組成,輸出
`成果.xlsx`／`sites.shp`／`features.geojson`(格式與舊 fishpv 相同,圖6 不用改)。
- **須用 QGIS 內建 python**(要 osgeo/GDAL);色碼表已 vendor 在 `config/luimap_colortable.csv`。
- `--reuse-landuse <既有landuse.tif>` 可跳過圖磚下載(重跑/驗收用)。
- **來歷**:自 fishpv 忠實移植(門檻與道路關鍵字一字不動),東石 57 案場逐案比對

### Ⓒ 隔離綠帶或設施（★★農業用地變更案必做，2026-08-02 納入產線）

**觸發條件**：基地為**農業用地**（農牧／養殖／水利／林業／生態保護／國土保安，
依農地變更要點§2②）且要變更作其他使用——**容許使用／變更編定／開發許可／都計變更
四條路線都適用**。法源＝辦法§6①（與相鄰農業用地應規劃隔離綠帶或設施）＋
要點§9（最小寬度1.5m、配置區位應與毗鄰農業用地相緊臨）＋§10（面積比）＋§11（隔離設施定義）。
**只要是農業用地變更案就補這一工項**，不要等使用者問。

四支腳本一條龍（全部系統 Python，**不需 QGIS**，除最後出圖）：

```powershell
# ⓵ 基地涉及公路時才跑：部分變更編定（道路分割出去維持農牧，綠帶分母＝分割後申請範圍）
python -X utf8 scripts\split_road.py --joined <面積join.shp> --features <案>\臨路評估\features.geojson `
    --neighbours <鄰地_面積join.shp> --out <案>\申請範圍

# ⓶ 綠帶本體（送審計算式用 --shape minimal；--facility-near 分類臨路側為隔離設施）
python -X utf8 scripts\greenbelt_ratio.py --joined <申請範圍.shp 或 面積join.shp> `
    --neighbours <鄰地_含保留地.shp> --facility-near <保留_道路.shp> `
    --only-on 農業用地 --shape minimal --min-width 1.5 --ratio 0.30 --out <案>

# ⓷ 送審計算式圖說（三角形分割、底×高÷2、比例檢核；內建正確性閘門）
python -X utf8 scripts\greenbelt_triangles.py --joined <申請範圍.shp> --retained <保留_道路.shp> --out <案>

# ⓸ 綠帶配置圖（＝③d 補充主題圖之一；正射底，隔離設施／隔離綠帶分色並列圖例）
& "<QGIS>\bin\python-qgis-ltr.bat" scripts\make_extra_maps.py --joined <申請範圍.shp> --case <案> --theme 隔離綠帶
```

⚠ ⓸ 是**出圖步驟**，需 QGIS 內建 python；跑在 ③ 那一段也可以（它就是 ③d 補充主題圖的
`--theme 隔離綠帶`）。⓵~⓷ 是系統 python、不需 QGIS，可在出圖前先跑完。

**六個非直覺處（都是實踩，違反會出錯或被審查打回）**：

1. **`--only-on 農業用地` 是必要的**：義務只對相鄰農業用地，**臨道路／未登錄地側不必留**。
   畫成全周界＝把義務算大，會多留綠帶、多拆建物。
2. **分母是「申請範圍」不是原地號**：部分變更編定時分割出去的道路不計入
   （前例反算驗證：1,585.396 ÷ 4,897.97 ＝ 32.37%）。
3. **`--shape minimal` 要配 `--ratio-max`**（預設 ratio+0.03）：無上限時「頂點最少」
   會把基地退縮到形狀最單純為止（實測退到綠帶 76.79%，讓掉大半土地）。
4. **銳角從基地端解決，不要修剪綠帶**：綠帶＝基地−可配置範圍，基地有銳角綠帶必然跟著有。
   事後修剪會破壞寬度合規（實測真不足 0→10/11 點）。用 `split_road` 的 `trim_spikes`
   在切分階段剔除，或靠 `greenbelt_ratio` 的 `chop_needles` 從可配置範圍截平。
5. **臨路側＝隔離設施、其餘＝隔離綠帶**（要點§11 隔離設施得為通路／空地等非建築開放性設施，
   兩者均計入面積比）。分界必須是**直線端點對接**、各為完整一段——不可用 buffer 交集
   （會有圓弧邊界與並排細長條）。
6. **`--neighbours` 要用平台官方鄰地層**：本機地籍是舊快照，近年變更編定的鄰地會判錯側
   （布袋306：南側其實臨特目用地免留設，用舊資料會多留 44 公尺）。

**🚧 閘門**：`greenbelt_triangles` 內建「三角形面積合計＝非綠帶區域面積」檢核，不符即中止；
`greenbelt_ratio` 的寬度檢核要「真不足 0 點」（交界收尾不算缺陷）。兩者任一不過＝停下回報。

**下游**：簡報「隔離綠帶劃設」頁＋「隔離綠帶面積計算式」頁（見 `parcel-briefing-deck`）。

這類點位圖資**,可用 OSM 初篩:
```powershell
python scripts\osm_sensitive_poi.py --joined <②joined.shp> --dist 200 --out <案>\OSM敏感設施初篩.csv
```
**定位必須寫清楚:OSM 是群眾協作資料,只能篩選,不能取代函詢。**
- 查到 → 幾乎確定有(距離仍須實測)｜**查無 ≠ 沒有**,一律仍須函詢
- **驗證覆蓋率再下結論**:先用 `--dist 1500` 對照——若連 1500m 都掛零,是 OSM 沒資料
  而非現地沒有,該次初篩無效。(安南案實測:1500m 內抓到 土城國小城西分班 467m、
  城西里活動中心 755m、place=hamlet「港西」606m/「十一戶子」669m → 覆蓋率可用,
  故「200m 內查無」有意義。)
- **臺灣鄉間 OSM 建物幾乎沒繪**:安南案 1500m 內住宅類建物 0 棟,但有 2 個聚落節點
  → **「十戶以上」不可用建物棟數判斷**,以 `place=hamlet/village` 節點為主要信號,
  戶數須以門牌資料或現場查證。
- **OSM 標籤≠法律用語,不可硬對映**:`amenity=place_of_worship`(寺廟/教堂)是否屬條文的
  「文教設施」須由主管機關認定 → 腳本單獨列為「（待認定）宗教場所」,不併入文教設施。
  逕行併入=假警報,逕行排除=可能漏判(該廟若為古蹟則落在「名勝古蹟」款)。
- 實測坑:**Overpass 裸鍵選擇器**(`["healthcare"]`/`["military"]`/`["historic"]`)會全鍵掃描
  而掛住,一律給值約束;用 `nwr` 取代 node/way/relation 三份;公共 API 會回 **504/429**,
  腳本已內建退避與鏡像切換,連續查詢請間隔數十秒。量大或要離線重跑→改抓 Geofabrik
  台灣 .osm.pbf 本機處理。
- **權威來源(法定認定用,OSM 只是前哨)**:學校=教育部全國各級學校名錄；醫療=衛福部
  醫事機構名冊(多為地址、需地理編碼)；社福=衛福部社會福利機構名冊；
  聚落戶數=內政部門牌位置資料/村里界圖；**營區不公開,一律函詢國防部**。

### ③b 存 QGZ 供修編(★產簡報前必做,使用者定案)
出圖時**不要帶 `--no-qgz`**(預設就會寫),完成後即產 `<案名>_maxmap.qgz`——內含全部
圖層(gpkg 複本/底圖 tif)與**每主題一個 Layout**,使用者可在 QGIS 開啟手動修編再匯出。
若先前為求快帶過 `--no-qgz`,產簡報前補跑一次
`make_maps <案名> --trust-shp ... --skip-extract --layout maxmap`(重用 gpkg 與底圖快取,
只重算圖與寫 qgz)。**確認 qgz 存在且可開(層/Layout 齊)才進 ④**。

### ④ 簡報產製 → 用 `parcel-briefing-deck`
出圖完成後,以 ①的屬性 Excel＋③的 圖層.gpkg/圖檔_maxmap(＋②c 臨路成果,若有)產
評估案簡報:先 `case_stats.py` 實算統計(數字只能來自這份 JSON,範本敘述句要覆核,
不可照抄),再依 **v1 定案格式(9 頁)** 組 pptx 並跑 validate＋逐頁目視 QA。
