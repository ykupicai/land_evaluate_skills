## 專案清單規則

權威來源 = 報帳工具根目錄的 Excel「專案訂單查詢.XLSX」(由 Ragic 匯出;比 data-inquiry/3 完整,約 207 筆)。
欄索引:專案名稱=8、訂單現況=5、接案團隊=20。**排除 訂單現況=已結案**(留 執行中/進行中/暫緩/待解約,約 123)。
- 專案名稱是 Ragic **連結欄位**:只吃完全正確的值,送錯(例如只送關鍵字)會被清空 → 一律送 match 命中的完整名稱。
- 接案團隊:Ragic UI「選專案自動帶團隊」是 link-and-load,**API 建單不會觸發** → 必須自己從 Excel 對照查出後主動送。
  少數多團隊專案 Excel 值是「A|B|C」管線分隔,照原樣送。

## 權限現況(2026/06)

- 一般同仁(例:吳依珊 ykupic.wys)的個人金鑰:可讀(只見自己的資料)、**無 API 寫入權**(POST 被當 guest)。
- 報帳機器人採方案 A:本人填了金鑰但無寫入權 → **不退共用金鑰**,直接擋下請他找管理者開通
  (避免別人的單掛到共用帳號 ykupic.lca 名下、跑進管理者的檢視)。跳過金鑰者才用共用金鑰建單。
- 簽核流程是手動的(本人在 Ragic 按送出),機器人不涉入。
