## ① API:建「表頭＋專案比例」草稿(免瀏覽器、免登入)

在專案根目錄執行(PowerShell 先設 `$env:PYTHONIOENCODING='utf-8'` 避免中文亂碼):

```
python ragic_fill_api.py 2026/06 --dry-run          # 預覽(不寫入),檢查比例與內容
python ragic_fill_api.py 2026/06                     # 互動確認後建立
python ragic_fill_api.py 2026/06 --auto              # 不詢問直接建(排程用)
python ragic_fill_api.py 2026/06 --from 1 --to 15 --force   # 指定期間從/至;--force 略過當月重複檢查
```

腳本會送:員工編號、期間從/至(預設整月)、**員工姓名(兩個欄位都送,見下)**、部門/職稱、
專案比例子表(沿用上一筆範本或 `PROJECTS`,含工作內容)。**不送**工時詳細列。

### 工作內容說明要寫到「目的層級」
機械掃描(`scan_content` 走 `FOLDER_MAP` 對應的案件資料夾當月異動)只會列檔名,**太粗**。
務必讀檔名、必要時開文件,改寫成「**做了什麼文件、為何發文**」:
- 「送印」→「送印開發計畫(第六次送件版)」
- 「公文」→「以衍古字第○號函檢送 5-6 月工作月報予臺南市府」(發/收文帶**文號與受文者**)
- 圖檔連拍(大量 jpg/png)摺疊計數、不逐張列。

精修後寫回的兩種方式:(a) 在 `ragic_fill_api.py` 的 `PROJECTS` 填 `content` 再建單;
(b) 對已建草稿用 API 更新該列 `1000252`——**以真實 row id 更新,勿用負號**(負號會新增重複列)。
取 row id:`GET …/invoice-form/6/{ragicId}?api&v=3` 看 `_subtable_1000246` 的鍵。
無資料夾異動的專案(如標案準備)內容留空,需向使用者確認該月實際做了什麼再補。

## ② Chrome:UI 產生工時 + 處理檢核

需要 Claude-for-Chrome 擴充連上(見 ③)。在**已登入**的 Ragic 分頁操作該草稿。

1. 開草稿 `…/invoice-form/6/{ragicId}`,確認**期間從/至**與員工姓名正確。
2. 右側「**動作 & 報表**」→ 點「**當月日期產製**」→ 彈窗按「**是**」。
   - ⚠️ 此按鈕**生成整月工作日**(週末自動跳過),**不受期間至限制**。若只想要半月,
     產製後刪掉多餘日列;若保留整月,記得把**期間至改成月底**(否則法定總工時=半月、
     實際=整月,看起來像爆量加班)。改期間至:點該欄→改 `yyyy/MM/dd`→存檔,法定工時會連動。
3. **雙擊**工時詳細第一欄區的「**起始時間**」儲存格 → 系統**一次帶入整月**上下班時間、
   請假資料與「**工時檢核結果**」。會進入編輯模式(出現「儲存/取消」);若彈出時間下拉,
   點空白處關掉、**不要改**已帶入的值。
4. 逐列看「**工時檢核結果**」:🟢 正常 = OK;**出現 X = 當天有請假** → 調整上下班時間,
   或**刪除整列**。處理完按「**儲存**」。
5. 確認專案比例子表為實際專案/比例(合計 **100%**)與工作內容。
6. **由林哲安本人**檢視後按「**開始簽核**」送出——這步**不可逆,Claude 不代按**。

### 操作要點
- 用 `browser_batch` 串多個動作(點擊+等待+截圖)較快;動作後截圖確認狀態。
- 動作按鈕的確認彈窗、儲存後常需短暫等待(`wait` 2~3 秒)再截圖。
- **session 過期會被導回 `login.jsp`**:Claude **不輸入密碼、不代按登入**(安全紅線)→
  請使用者本人重新登入(已執行完畢的動作已存檔,不會遺失),再續做。

`select_browser` 選 device "yku" → `navigate` 到草稿。
完整設定(捷徑內容、開機自動開/取消、每月排程 `ragic_reminder.ps1`)見
