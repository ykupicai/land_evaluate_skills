# 工作時間記錄表單（invoice-form/6）欄位編號

> 本檔是 `<專案根>\.claude\ragic_form6_fields.md` 的鏡射（2026/06 實測快照），
> 讓本 skill 不依賴專案 checkout 也能查欄位。若兩邊不一致，以專案檔為準並回頭更新本檔。

2026/06 用共用金鑰實測探查（空更新法 + 測試建單）。server = `ap13.ragic.com`，帳號 = `YKU`。

> ✅ 表頭與專案比例子表**可用 API 寫入**：員工姓名/部門/職稱需明確送（不會自動帶）；
> 專案名稱是連結欄位要送全名；日期一律 yyyy/MM/dd。實作見專案根 `ragic_fill_api.py`。
>
> ⚠️ **工時詳細列（`_subtable_3001017`）改由公司新版 UI 流程產生，不再逐日 API 手填**：
> 存檔表頭+專案比例草稿後，於 Ragic「動作&報表」點「當月日期產製」一次生成當月工時列，
> 再雙擊「起始時間」由系統帶入上下班/請假/檢核結果（檢核 X＝當天請假，需調整時間或刪列）。
> 早期「API 直送起始日讓 server 帶打卡時間」之作法在新版流程下未經實測，腳本預設不送
> （僅 `--with-hours` 保留，供測試、需重新驗證）。
