# 地籍評估案簡報產製

**版面狀態:已定案(v1,2026-07-15)。** 格式基準=使用者修正後的官田 v1:
`大量圖資轉換工具/outputs/20260707官田maxmap/20260707官田綠能設施興建評估_簡報_v1.pptx`
(9頁)。新案以 v1 為結構藍本,不要回退 7 頁初版。

## 前置:先有 QGZ 再做簡報(使用者定案)

產簡報前確認 `<案名>_maxmap.qgz` 已存在(make_maps 預設會寫;帶過 `--no-qgz` 就補跑
`--skip-extract` 產出)——使用者要能在 QGIS 開專案修編圖面。qgz 含全部圖層與每主題
Layout;若使用者修編後重匯出了某張圖,簡報改用修編後的版本。

## 原則:數字全部實算,不抄範本句

先跑 `scripts/case_stats.py` 把統計算出來,簡報**只能寫這份 JSON 有的數字**:

```powershell
python scripts/case_stats.py --xls <屬性.xls> --gpkg <圖層.gpkg> --sites <sites_status.csv> -o stats.json
```

範本的敘述句要覆核,不可照抄——官田案範本寫「土地權屬皆為私有地」,實算是
**144 私有＋1 公有**(番子渡頭段157,國產署),照抄就寫錯。同理「鄰近道路系統」不可憑
印象寫:裁切正射套疊 PNG 讀 NLSC 路名標示(官田案讀到 國道3號/官田系統交流道),
並用 sites_status 的臨路狀態佐證。

## 頁面組成(v1 定案,9 頁)

| 頁 | 內容 | 圖 | 資料 |
|---|---|---|---|
| 1 | 封面:案名三行式,結尾「**光電開發評估案**」+日期+雙藍線 | — | sections/first_landno |
| 2 | 基礎資料·區位:段/筆數、權屬(公有地逐筆點名)、面積 ha(m²)、鄰近道路 | 正射套疊 | stats + 圖面判讀 |
| 3 | **土地使用分區及編定**·非都市土地使用分區:筆數/面積+表 | 使用分區圖 | zoning |
| 4 | **土地使用分區及編定**·非都市土地使用地編定:總表 + 「**各宗基地用地組成**」表(宗基地×用地×面積×比例,S001..) | 使用地編定圖 | landtype + 各宗基地統計 |
| 5 | 國土功能分區草案:各分區 ha/佔比+表(草案示意、以公告為準) | 國土功能分區圖 | functional |
| 6 | 環境敏感地:讀 `環境敏感套疊.csv` 填表(全無套疊寫「經查詢均無套疊」) | **本機環敏套疊圖**(禁限建/淹水依深度分級/**轄區排水路藍線+DR_NAME label**,保留透明度) | 環境敏感套疊.csv + 環境敏感相關/ 圖資 |
| 7 | 臨路條件檢核:各宗基地臨路狀態+**道路寬度**(如「寬度均不足8m」)+表 | 臨路判定圖(EMAP2+外擴見分類道路) | road + 寬度資訊 |
| 8 | **隔離綠帶劃設**:buffer-greenbelt 成果+各宗基地可行性說明 | 緩衝綠帶圖 | buffer-greenbelt |
| 9 | **綜合說明**:評估總表(列=評估項目,記號 ○=具可行性 △=有條件辦理 ╳=不具可行性) | — | 各頁結論彙整 |

各宗基地用地組成的算法:gpkg 基地層以正規化地號 join `sitemap.csv` → 依(案場×使類)
加總幾何面積、算站內比例(官田:S001 農牧88.2%+林業11.8%,S002–S004 全農牧)。

地圖用 `圖檔_maxmap/` 的成果(A4 橫式 1.414 比,右側 w8.45");臨路判定若只有舊版面
成品,PIL 裁掉頂部 6.2% 標題列再用。

## 版面樣式(v1 定案)

16:9(`LAYOUT_WIDE`)、微軟正黑體。每頁:淡灰虛線網格 PNG 滿版打底 + 黑色外框。
內容頁頁首:黑主標粗體 + 紅(C00000)副標**緊接主標右側** + 頁首底線 + 右上頁碼。
條列符號用「**・**」(v1 使用者定案;非 ■)。統計表:灰表頭(E7E7E7)、灰框線 0.75pt。
封面:置中粗體三行案名、頁尾雙藍線(2.5pt+1pt)+日期。

**新案兩種做法**:(a) 以 v1 pptx 為藍本複製後置換內容——文字/統計用 python-pptx 改、
地圖用 zip 層級換 media(`blip.rEmbed` → `related_part(rId)._blob = bytes`),新增表格
記得手動補灰框線(python-pptx 預設無框,`a:tcPr` 加 `a:lnL/R/T/B`);或 (b) 用
[references/build_deck_template.js](references/build_deck_template.js) 產前 7 頁基底
(注意:該產生器仍為 ■ 條列與舊標題用語,產後需依 v1 調整,並補第 8/9 頁)。優先 (a)。

## 工具鏈與本機注意(踩過的坑)

- pptxgenjs 全域安裝後 node 找不到 → `export NODE_PATH=$(npm root -g)` 再跑。
- pptx skill 的 `validate.py` 在 Windows 要 `PYTHONUTF8=1`,否則 cp950 讀 SKILL/中文檔炸。
- pptx skill 的 `soffice.py` 包裝在 Windows 失敗(AF_UNIX)→ 直接呼叫
  `"C:\Program Files\LibreOffice\program\soffice.exe" --headless --convert-to pdf`。
- `pdftoppm` 沒裝 → 用 PyMuPDF(`fitz`)把 PDF 逐頁存 jpg。
- 地圖 PNG 是 RGBA,存 jpg 前先 `.convert('RGB')`。
- QA 必做:validate 全過 + 每頁渲染目視(溢出/重疊/佔位殘留)。
