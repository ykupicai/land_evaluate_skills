# 地籍查詢 cadastre-check

輸入地段地號，輸出**官方界址環 + 官方登記屬性**的 Shapefile。

```
python scripts/check.py 高雄市 路竹區 保安段 711-3
python scripts/check.py 臺東縣 臺東市 豐橋段 2 2-2 2-3 3 3-1     # 多筆組成基地
```

## 最上位原則

**這份圖資是評估用，不是界址。** 形狀只求相對正確；**面積等會被形狀影響的數值一律以內政部登記值為準**。輸出的 `圖面積` 欄僅供對照，`登面積` 才是官方數字。

實測幾何精度（對登記面積）：多數 ±0.5% 內；小宗地的圖解法數化誤差較大，21 m² 的實測 −3.3%。這是常態，不是錯誤。

## 資料來源分工

| 項目 | 來源 | 費用 |
|---|---|---|
| 界址環（幾何） | 農業部地籍圖資 `coagis.colife.org.tw` | 免費免帳號 |
| 登記屬性 | 內政部 NLSC `api.nlsc.gov.tw/S09_Ralid/getLandInfo` | 免費免帳號 |
| 都市計畫圖 | 內政部 URBAN 圖磚 | 免費，需 Referer |

正式界址向量資料請至**國土測繪圖資 e 商城**購買。本工具用免費資源取得評估足夠的形狀，不取代它。

## 五種結論

| verdict | 顯示 | 意義 |
|---|---|---|
| `OK` | 查得到 | 取得界址環，產出 SHP |
| `RESURVEYED` | 已重測改號（已追蹤到新地號） | 舊地號查無，經新舊對照追到後繼地號，**照樣出圖** |
| `MISMATCH` | 查無此地號（API 回傳別筆地，已拒絕） | 見下方安全閘門 |
| `NOT_FOUND` | 查無 | API 明確回空。本島罕見，**離島是常態**（見限制） |
| `ERROR` | 查詢失敗 | 段名不存在且無對照、連線失敗等，訊息會說明原因 |

## 重測改號自動追蹤

輸入舊地號查不到時，會自動走內政部新舊地號對照追到後繼地號再取幾何，兩種情境都涵蓋：

- **段名已消失**（如松羅一段、小南灣段下福小段）：回舊版次的段清單拿舊段碼，再送對照。
- **段名還在但地號重編**（如四重溪段 20-13、北勢段 115）：先被 14 碼閘門擋下，再走對照追回。

**後繼地號一定要走內政部這支，絕不可拿農業部模糊比對攔下的那筆充當。** 實測四筆重測案，模糊比對給的 671／687／166／23-2 全部不是真後繼，正解是 641／1479／1067／179——採信會四筆全錯。

重測後的地籍是**數值法**成果，幾何與登記面積吻合到 ±0.03% 以內，比一般圖解法段更準。

```
查詢：屏東縣 車城鄉 四重溪段 20-13
  回傳不符（得 TE061400230002），改查新舊地號對照…
  ✔ 追蹤到新地號：溫泉東段 179
  界址環：6 頂點，圖面積 1639.10 m²
  登記：面積 1639.12 m²，一般農業區／農牧用地
  結論：【已重測改號（已追蹤到新地號）】
```

追蹤成功後，**屬性查詢與 SHP 欄位一律使用新地號**；原查詢地號保留在 `代碼.原查詢地號8碼`。

## ★ 安全閘門：回傳 14 碼必須完全相符

**農業部這支 API 查不到時會回「別筆地」，而且會跨縣市。** 實測：

- 查「新北市 林口區 小南灣段下福小段 788」→ 回「**臺南市永康區**南灣段231地號」
- 查「屏東縣 車城鄉 四重溪段 20-13」→ 回「四重溪段 **23-2**」
- 查不存在的「考試潭段鹿寮小段 9999」→ 回同段「**347**」

因此 `moa.parcel()` 一律驗證回傳的 `Return14SecNo` 與請求的 14 碼（段碼＋地號8碼）完全相同，不符即拒絕；接著會再走一次新舊地號對照（見下節），追不到才回報 `MISMATCH`。**沒有這道閘門，這條管線會靜默產出錯誤幾何**——這是它最危險的失效模式，改動時不可移除。

連帶效果：因為 API 幾乎總會回某筆地，「這筆地不存在」實務上是以 `MISMATCH` 呈現而非 `NOT_FOUND`。看到 `MISMATCH` 的正確解讀是「此地號在該版次不存在（可能已重測、分割或段名變更）」。

## 版次

**預設一律用最新版次**（動態解析，不寫死）。

```
python scripts/check.py --list-versions          # 目前共 57 個，最新 115Apr
python scripts/check.py <縣市> <鄉鎮> <段> <地號> --version 113Dec   # 指定舊版次
```

版次確實生效，可用「已知分割時點」驗證：豐橋段 2-3 在 112 年 6 月分割，查 111Dec～112Jun 得 57.30 m²（分割前），112Aug 起得 21.65 m²（分割後）。

亂填版次會誠實回查無，不會默默退版。版次有兩種寫法——早期 `105Q2`（季）、之後 `114Dec`（雙月）——排序要能同時處理，排錯會靜默拿到舊資料。

## 名稱體系與內政部不同

農業部用「**台**東市」不是「臺東市」；**嘉義市底下只有一個「嘉義市」**，沒有東區／西區。所以縣市／鄉鎮／段名一律先用官方清單解析成官方寫法（`GetCountyList`／`GetTownList`／`GetSectionList`），並做臺／台與空白正規化。使用者兩種寫法都能輸入。

```
python scripts/check.py 臺東縣 臺東市 --list-sections     # 列出該鄉鎮所有段名與段碼
```

## 輸出

輸出位置依序取自 `--out-dir`、`config.json` 的 `output_dir`、當下工作目錄的 `cadastre_out/`。所有檔名都帶 `YYYYMMDD_HHMMSS` 時間戳——每次執行都產圖，不帶時間戳會靜默蓋掉上一次的成果，而地籍隨時間變動，舊成果本身就是紀錄。

### `<事務所碼><段碼>_<地號|site>_<時間戳>.shp`

查得到的每一筆一個圖徵。單筆查詢用地號命名，多筆用 `site`。

| 欄位 | 說明 |
|---|---|
| `段號` | 14 碼（事務所2＋段碼4＋地號8） |
| `登面積` | **內政部登記面積——以此為準** |
| `圖面積` | 幾何實算，僅供對照 |
| `使分`／`使類` | 使用分區／使用地類別（都市土地為空，見下） |
| `公告值`／`公告價` | 公告現值／公告地價 |
| `版次` | 該幾何的地籍版次 |
| `幾何源`／`屬性源` | 來源標註 |
| `品質` | 註明評估用途、圖面積偏差 |

環向為順時針（ESRI 外環慣例），座標 TWD97 TM2 / EPSG:3826，附 `.prj`。

### `*_urban.png`（使用分區為空時）

都市計畫區土地沒有使用分區欄位——`getLandInfo` 的使用分區／使用地類別只適用非都市土地，都市土地一律回空值（抽樣 40 筆使分為空的地號，38 筆現況 API 也是空的：不是缺漏，是不適用）。偵測到空值時輸出都計圖切片供人工判讀，**刻意不做自動判讀**，分區以顏色與文字標註表示，判錯代價太高。

一次查多筆只產一張、涵蓋全部地號並各自標號。每筆各產一張的話，多筆基地會得到好幾張內容幾乎相同、而且紅框只有一筆的圖，實測會讓人把單筆的框當成整個基地的形狀。

**分區界線不貼合地籍界線是正常的**，兩套獨立的圖。實測臺南市仁德區保甲段五筆基地全部落在同一片「國小學校用地」內，而該分區範圍遠大於基地。

## 限制

- **不是界址。** 農業部圖資是圖解法數化成果，不可作為界址依據。
- **小宗地偏差較大。** 21 m² 的實測 −3.3%，數十 m² 以上多在 ±0.5% 內。面積一律用登記值。
- **token 會輪替。** 放在公開靜態檔，每次執行重抓；若官方改為綁 session，幾何功能會失效（屬性查詢不受影響）。
- **離島沒有幾何資料。** 澎湖、金門、連江的**段清單完整**（望安鄉 37 段、金湖鎮 52 段、南竿鄉 12 段），但界址環一律回空 -> `NOT_FOUND`。對照本島：同樣隨手查一個地號 1 都拿得到幾何。所以離島查不到不是段名寫錯，是幾何服務沒有那些資料。
- **重測改號會自動追蹤**（見上節），但若內政部對照無資料（該筆已滅失、或尚未建檔）就只能回報查無。
- **更新節奏依農業部**，目前約雙月一版。
- 新舊地號對照走內政部 `openapi.moi.gov.tw`，單次最多 25 筆。

## 在地籍評估產線中的位置（2026-08-02 納入）

本 skill 是 `cadastral-map-pipeline` 的 **⓪a 免登入先跑一輪**，橋接腳本＝
`大量圖資轉換工具/scripts/cadastre_fetch.py`（`fetch` 產產線可吃的 shp、`verify` 與平台對帳）。

**布袋306 七筆逐項對帳（實測，非推測）**：幾何**與 TCDGIS 官方 shp 完全相同**
（IoU 100.00%、面積差 0.00 ㎡、質心位移 0.00 m、頂點同為 22，七筆圖面積全部等於平台
向量面積）；登記面積＝平台標示面積；使分／使類 7/7 一致——**綠帶應留設側判定所需的
欄位，本 skill 就夠，不必為此登入平台**。

**三件事本 skill 拿不到，那些需求仍須上 TCDGIS**：

1. **公私別／所有權人／管理者**——`getLandInfo` 回傳的 20 個欄位裡沒有（AA05/06/08/09/
   10/11/12/16/17/21~24/27/45/46/48/49、ABMAX、ACMAX，已實測列舉）。權屬決定因應手段
   （國有水利地買不到、只能申請搭版橋），**不可用本 skill 成果推論權屬**。
2. **環境敏感地區套疊分析 53 項**——只有 TCDGIS 有。
3. **離島幾何**——見上方限制。

分工結論：**本 skill 負責幾何與地籍屬性，TCDGIS 那次登入縮到只為「權屬＋環敏」**。
送審交付的基地幾何權威仍以平台官方 shp 為準（使用者 2026-07-15 鐵律）；
升為主來源前每案跑一次 `verify` 累積證據（IoU ≥99.9% 且面積差 ≤0.1% 才算通過）。

## 串接其他專案

三種介面，擇一使用。**面積一律用 `registry.area`（官方登記值），不要用 `map_area`。**

### 1. Python 直接匯入（推薦）

```python
import sys; sys.path.insert(0, "<skill>/scripts")
from api import query, to_geojson

r = query("臺東縣", "臺東市", "豐橋段", ["2-2", "3"])
r["version"]                 # '115Apr'，實際使用的地籍版次
r["summary"]                 # {'total': 2, 'ok': 2, 'failed': 0}

for rec in r["records"]:
    if not rec["ok"]:
        print(rec["status"], rec["message"]); continue
    rec["parcel"]["code14"]      # 'VA006800020002'
    rec["registry"]["area"]      # 1.92  ← 官方登記面積，以此為準
    rec["geometry"]              # GeoJSON Polygon，EPSG:3826
    rec["map_area"]              # 1.9167 幾何實算，僅供對照
    rec["deviation_pct"]         # -0.17

gj = to_geojson(r)               # FeatureCollection
```

不產生任何檔案。要 SHP／都計圖請走 CLI。

### 2. CLI ＋ JSON（跨語言）

```
python scripts/check.py <縣市> <鄉鎮> <段> <地號>... --api-json --no-shp
python scripts/check.py <縣市> <鄉鎮> <段> <地號>... --geojson  --no-shp
```

### 資料契約

`api.SCHEMA`（目前 `1`）在格式變動時會 +1，呼叫端可以檢查。

**每筆 record 的鍵固定不變**，不論成功或失敗都一樣，只有值不同——呼叫端只要看
`ok` 與 `status`，不必為每種結論寫不同解析。

| 欄位 | 說明 |
|---|---|
| `ok` | bool。只有 `OK`／`RESURVEYED` 為 true |
| `status` | `OK`／`RESURVEYED`／`MISMATCH`／`NOT_FOUND`／`ERROR` |
| `query` | 你輸入的 city/town/section/landno |
| `parcel` | 實際命中的 code14／city／town／section／landno／landno8 |
| `geometry` | GeoJSON Polygon，**EPSG:3826**（非經緯度） |
| `registry` | area／zone／land_type／current_value／land_value／reg_date |
| `map_area`／`deviation_pct` | 幾何實算面積與對登記面積的偏差% |
| `resurveyed_from` | 重測追蹤時的原查詢地號，否則 `null` |
| `rejected` | 安全閘門擋下的內容，供除錯，**絕不可當結果** |
| `notes`／`warnings` | 說明與警告字串陣列 |

三個容易踩的點：

1. **重測改號時 `query.landno` 與 `parcel.landno` 不同**——`parcel` 是追蹤後的新地號，
   幾何與屬性都是新的。要顯示對照就看 `resurveyed_from`。
2. **座標是 TWD97 TM2／EPSG:3826，不是經緯度。** GeoJSON 規格預設 WGS84，
   有些工具會誤判，匯入時請明確指定 EPSG:3826。
3. **GeoJSON 外環是逆時針**（RFC 7946），與輸出的 Shapefile（順時針，ESRI 慣例）
   相反。這是兩邊規格不同，不是 bug。
