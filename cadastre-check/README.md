# cadastre-check

輸入地段地號，輸出**官方界址環 + 官方登記屬性**的 Shapefile。全程免費、免帳號。

```bash
python scripts/check.py 高雄市 路竹區 保安段 711-3
```

```

幾何來源：農業部地籍圖資　屬性來源：內政部 NLSC

──────────────────────────────────────────────────────────────
查詢：高雄市 路竹區 保安段 711-3
──────────────────────────────────────────────────────────────
  EJ282007110003  高雄市路竹區保安段711-3地號
  界址環：6 頂點，圖面積 255.94 m²
  登記：面積 255.86 m²，／，登記 民國113年11月19日

  結論：【查得到】

SHP：...\地籍成果\EJ2820_711_3_20260803_224629.shp（1 筆圖徵）
```

---

## 核心原則

**這份圖資是評估用，不是界址。**

形狀只求相對正確；**面積等會被形狀影響的數值一律以內政部登記值為準**。輸出的 `圖面積` 欄僅供對照，`登面積` 才是官方數字。需要界址請至國土測繪圖資 e 商城購買正式向量資料。

## 快速開始

### 需求

- Python 3.8+
- Pillow（僅都市計畫圖切片需要：`pip install pillow`）
- 網路連線

不需要任何本機底圖——舊版需要的 27 GB 地籍 SHP 與索引已不再使用。

### 設定

`config.json`（可省略，省略時輸出到當下目錄的 `cadastre_out/`）：

```json
{
  "cache_dir": "",
  "output_dir": "C:/path/to/成果"
}
```

### 驗收

```bash
python scripts/selftest.py     # 純邏輯，不連網
python scripts/regress.py      # 案例回歸，需網路
```

## 使用

```bash
python scripts/check.py <縣市> <鄉鎮市區> <段名> <地號> [地號2 ...]
```

| 參數 | 說明 |
|---|---|
| `--out-dir <路徑>` | 輸出目錄 |
| `--version <版次>` | 指定地籍版次，預設用最新 |
| `--no-shp` | 只查詢不產圖 |
| `--json-only` | 只輸出 JSON（人看的中文鍵格式） |
| `--api-json` | 只輸出串接用 JSON（ASCII 鍵、結構固定） |
| `--geojson` | 只輸出 GeoJSON FeatureCollection（EPSG:3826） |
| `--list-versions` | 列出所有版次 |
| `--list-sections` | 列出該鄉鎮所有段名與段碼 |

地號可寫 `306`、`306-1` 或 8 碼 `03060001`，三種皆可。多筆地號一次查會產出**單一 SHP**，適合以數筆土地組成基地的情境。

## ★ 安全閘門：回傳 14 碼必須完全相符

**農業部這支 API 查不到時會回「別筆地」，而且會跨縣市。** 實測：

| 查詢 | API 回傳 |
|---|---|
| 新北市 林口區 小南灣段下福小段 788 | **臺南市永康區**南灣段 231 地號 |
| 屏東縣 車城鄉 四重溪段 20-13 | 四重溪段 **23-2** |
| 考試潭段鹿寮小段 9999（不存在） | 同段 **347** |

因此 `moa.parcel()` 一律驗證回傳的 `Return14SecNo` 與請求的 14 碼完全相同，不符即拒絕。**沒有這道閘門，這條管線會靜默產出錯誤幾何**——改動時不可移除，回歸測試有七個案例釘住它。

擋下之後會再走一次新舊地號對照（見下節）；若對照也追不到，才回報 `MISMATCH`。因為這支 API 幾乎總會回某筆地，「這筆地不存在」實務上以 `MISMATCH` 呈現而非 `NOT_FOUND`：

```
查詢：嘉義縣 布袋鎮 考試潭段鹿寮小段 9999
  回傳不符（得 QB141003470000），改查新舊地號對照…
  ✖ 已拒絕；新舊地號對照無資料（可能未重測，或該筆已滅失）

  結論：【查無此地號（API 回傳別筆地，已拒絕）】
    ⚠ 此地號在版次 115Apr 已不存在（重測、分割或段名變更）。
```

## 重測改號自動追蹤

輸入舊地號查不到時，會自動走內政部新舊地號對照追到後繼地號再取幾何。兩種情境都涵蓋：

| 情境 | 例子 | 處理 |
|---|---|---|
| 段名已消失 | 松羅一段、小南灣段下福小段 | 回舊版次的段清單拿舊段碼，再送對照 |
| 段名還在、地號重編 | 四重溪段 20-13、北勢段 115 | 先被 14 碼閘門擋下，再走對照追回 |

```
查詢：屏東縣 車城鄉 四重溪段 20-13
  回傳不符（得 TE061400230002），改查新舊地號對照…
  ✔ 追蹤到新地號：溫泉東段 179
  界址環：6 頂點，圖面積 1639.10 m²
  登記：面積 1639.12 m²，一般農業區／農牧用地，登記 民國114年12月04日
  結論：【已重測改號（已追蹤到新地號）】
```

**後繼地號一定要走內政部這支，絕不可拿農業部模糊比對攔下的那筆充當。** 實測四筆重測案：

| 舊地號 | 模糊比對給的（錯） | 內政部對照的真後繼 |
|---|---|---|
| 龍蛟潭段 621-149 | 671 | 龍蛟新段 641 |
| 內甕段 681-4 | 687 | 新內甕段 1479 |
| 北勢段 115 | 166 | 新三角段 1067 |
| 四重溪段 20-13 | 23-2 | 溫泉東段 179 |

四筆的模糊比對結果**全部是錯的**——若當初採信，四筆全會拿到別人的土地。

重測後的地籍是**數值法**成果，幾何與登記面積吻合到 ±0.03% 以內，比一般圖解法段更準。追蹤成功後屬性查詢與 SHP 欄位一律使用新地號，原查詢地號保留在 `代碼.原查詢地號8碼`。

## 版次

預設用**最新**版次，動態解析不寫死。

```bash
python scripts/check.py --list-versions
# 共 57 個版次，最新 115Apr：
#   113Jun、113Aug、113Oct、113Dec、114Feb、114Apr、114Jun、114Aug、114Oct、114Dec、115Feb、115Apr
```

版次確實生效，用「已知分割時點」驗證過——豐橋段 2-3 在民國 112 年 6 月 20 日分割：

| 版次 | 圖面積 |
|---|---|
| 111Dec ／ 112Feb ／ 112Jun | 57.30 m²（分割前） |
| 112Aug | 21.73 m² |
| 112Dec ～ 115Apr | 21.65 m²（分割後） |

亂填版次（`999Xxx`、空字串、`116Dec`）一律回查無，不會默默退版。

版次有兩種寫法：早期 `105Q2`（季）、之後 `114Dec`（雙月）。排序邏輯要能同時處理，排錯會靜默拿到舊資料——selftest 有案例釘住。

## 名稱體系與內政部不同

農業部用「**台**東市」不是「臺東市」；**嘉義市底下只有一個「嘉義市」**，沒有東區／西區。

縣市／鄉鎮／段名一律先用官方清單解析成官方寫法並做臺／台正規化，使用者兩種寫法都能輸入。段名找不到時會明確報錯並附該鄉鎮的段數，不會猜：

```
✖ 新北市 林口區 在版次 115Apr 查無段「小南灣段下福小段」（該鄉鎮共 33 段）
```

（這通常代表該段已因重測改名。）

## 輸出

所有檔名帶 `YYYYMMDD_HHMMSS` 時間戳。每次執行都產圖，不帶時間戳會靜默蓋掉上一次的成果，而地籍隨時間變動，舊成果本身就是紀錄。

### Shapefile

查得到的每一筆一個圖徵；單筆用地號命名，多筆用 `site`。

| 欄位 | 說明 |
|---|---|
| `段號` | 14 碼（事務所2＋段碼4＋地號8） |
| `縣市`／`鄉鎮`／`段` | 官方寫法 |
| `宗地母`／`宗地子`／`地號` | 地號組成 |
| `登面積` | **內政部登記面積——以此為準** |
| `圖面積` | 幾何實算，僅供對照 |
| `使分`／`使類` | 使用分區／使用地類別 |
| `公告值`／`公告價` | 公告現值／公告地價 |
| `登日期` | 登記日期（民國） |
| `版次` | 該幾何的地籍版次 |
| `幾何源`／`屬性源`／`品質` | 來源與品質標註 |

環向順時針（ESRI 外環慣例），座標 TWD97 TM2 / EPSG:3826，附 `.prj`。

### `report_<時間戳>.json`

完整結構化結果：代碼解析、幾何、屬性、警告。

### `*_urban.png`（使用分區為空時）

都市計畫區土地沒有使用分區欄位——`getLandInfo` 的使用分區／使用地類別只適用非都市土地，都市土地一律回空值（抽樣 40 筆使分為空的地號，38 筆現況 API 也是空的：不是缺漏，是不適用）。偵測到空值時輸出都計圖切片供人工判讀，**刻意不做自動判讀**，分區以顏色與文字標註表示，判錯代價太高。

一次查多筆只產一張、涵蓋全部地號並各自標號。每筆各產一張的話，多筆基地會得到好幾張內容幾乎相同、而且紅框只有一筆的圖，實測會讓人把單筆的框當成整個基地的形狀。

**分區界線不貼合地籍界線是正常的**，兩套獨立的圖。實測臺南市仁德區保甲段五筆基地全部落在同一片「國小學校用地」內，而該分區範圍遠大於基地。

## 限制

- **不是界址。** 圖解法數化成果，不可作為界址依據。
- **離島沒有幾何資料。** 澎湖、金門、連江的**段清單是完整的**（望安鄉 37 段、金湖鎮 52 段、南竿鄉 12 段），但界址環一律回空 -> `NOT_FOUND`。對照本島：同樣隨手查一個地號 1 都拿得到幾何。所以離島查不到不是段名寫錯，是幾何服務沒有那些資料。
- **重測改號會自動追蹤**（見下節）；若內政部對照無資料（該筆已滅失或尚未建檔）才回報查無。
- **token 會輪替。** 每次執行重抓；若官方改為綁 session，幾何功能會失效（屬性查詢與 `--no-shp` 不受影響）。
- **更新節奏依農業部**，目前約雙月一版。

## 檔案結構

```
cadastre-check/
├── SKILL.md              Claude Code skill 定義
├── README.md             本文件
├── config.example.json   設定範本
├── config.json           你的設定（不進版控）
└── scripts/
    ├── api.py            ★ 對外程式介面（其他專案從這裡串接）
    ├── moa.py            農業部地籍：版次、行政區與段清單、界址環（含 14 碼安全閘門）
    ├── check.py          CLI 主程式：查詢、SHP、都計圖切片
    ├── cadlib.py         座標轉換、Shapefile 讀寫、內政部屬性、圖磚
    ├── config.py         路徑設定
    ├── selftest.py       純邏輯自我測試（不連網）
    └── regress.py        案例回歸測試（需網路）
```

匯入關係：`api.py` → `check.py` → `moa.py` / `cadlib.py` / `config.py`。

## 串接其他專案

詳見 SKILL.md「串接其他專案」一節。最短路徑：

```python
import sys; sys.path.insert(0, "<skill>/scripts")
from api import query
r = query("臺東縣", "臺東市", "豐橋段", ["2-2", "3"])
rec = r["records"][0]
rec["registry"]["area"]   # 官方登記面積 —— 面積以此為準
rec["geometry"]           # GeoJSON Polygon，EPSG:3826
```

或跨語言走 CLI：`--api-json` / `--geojson`，離開碼 0／1／2 表示全部成功／部分失敗／全部失敗。

打包時排除 `config.json`（含個人路徑）、`.cache/`、`cadastre_out/`、`__pycache__/`。
