# 國土功能分區逐筆查詢（nluz 報部版）

用清冊的**段代碼＋地號**向內政部國土功能分區圖公展系統逐筆查權威分區，補上
**國土功能分區 / 原使用分區 / 原使用地 / 使用地** 四欄。

2026-07-26 以官田案真實清冊（145 筆、社子段等）實測走通。

## ★ 走「大量圖資轉換工具」產線的案子改用產線橋接（2026-08-06 起）

產線 ⓪a/⓪a' 已經有基地與鄰地 shp 時，**不要再手動組清冊餵本 skill 的 CLI**，改跑
`大量圖資轉換工具/scripts/nluz_landzone.py --case <案名>`（需 QGIS 內建 python）。
它沿用本 skill 的 `NluzClient`/節流/續跑邏輯，另外多做三件事：

1. **輸入吃 shp 不吃清冊**（`<案>/cadastre/基地.shp`＋`鄰地.shp`）。
2. **自動與本機 `國土功能分區/` 面圖層逐筆比對，不一致時 nluz 優先**並輸出覆蓋 gpkg，
   `make_maps.py` 出主題3 時自動套用（使用者 2026-08-06 定案）。
3. **依案型決定查不查鄰地**：非都市土地案查基地＋出圖範圍內鄰地；都市計畫案只查基地。

⚠ **跨分區宗地不覆蓋**：nluz 對橫跨多分區的宗地回**複合描述字串**（「部分海洋資源
地區第一類之一、部分…第三類、部分農業發展地區第二類」），這種值不在出圖 QML 的 21 類
分類表內、拿去覆蓋會讓該宗地上不了色，且本機面圖層對它反而更精確（真的切成多塊面）。
橋接已改為排除這類、出圖沿用本機切分。**自行處理 nluz 回傳值時要注意同一件事**：
`國土功能分區` 欄不保證是單一標準分區名，用 `zone_utils.extract_zones_from_text()`
可解析成分區清單。

## ⚠️ 三個硬限制（先跟使用者講清楚）

1. **只適用非都市土地的「使用地土地清冊」欄位**。都市計畫區與國家公園計畫區依法無須
   製作使用地土地清冊電子檔，那組欄位會回「查無」——**這是正常結果不是錯誤**，
   不要重試或當失敗處理。
   ⚠ **但「查無」不等於整筆沒有國土功能分區值**（2026-08-06 更正）：善化善南段案
   （都市計畫農業區、64 筆）實測 nluz **正常回「城鄉發展地區第一類」**。所以
   **都市計畫案這步仍值得跑**，別因為舊版這條限制就直接跳過。
2. **版本是報部版（草案）**。平台自述「查詢結果僅供參考，仍以直轄市、縣（市）政府認定內容為準」。
   交付文件請照此口徑寫，勿宣稱為定案。
3. **平台限流 5 秒**。腳本固定 5.5s 間隔，145 筆約 13 分鐘、300 筆約 28 分鐘。**快不了**，
   要嘛背景跑要嘛先 `--limit` 試跑。與 TCDGIS 的 10s 限制是**不同系統、不同秒數**，勿混用。

## 流程

```powershell
$S = "$env:USERPROFILE\.claude\skills\nluz-landzone-query\scripts\nluz_query.py"

# 1.(選用)看某鄉鎮的段名↔段代碼
python $S sections --county 臺南市 --town 官田區

# 2. 先試跑幾筆確認清冊欄位與段代碼對得上
python $S query --roster <清冊.xls> --county 臺南市 -o <out.csv> --limit 6

# 3. 全量(背景跑;中斷可直接重跑,checkpoint 會續跑)
python $S query --roster <清冊.xls> --county 臺南市 -o <out.csv>
```

- 清冊需含 **鄉鎮市區 / 地段名稱 / 地號**（TCDGIS 匯出的屬性 Excel 原生就有，欄名自動偵測）。
- **段代碼優先用清冊 `[4342]社子段` 的 4 碼比對**，對不到才用段名——因為異體字（頂茄芝來/頂加芝來、
  臺/台）會讓純段名比對失敗。兩者都對不到會標「失敗」並記下該鄉鎮平台實際段數，不會靜默跳過。
- 地號自動轉 8 碼（母號4+子號4 零埋）：`389`→`03890000`、`389-1`→`03890001`。
- **每 5 筆寫檔**，中斷不會白跑；重跑時已「有資料/查無」的不重查（`--overwrite` 才強制重查）。

## 輸出

CSV（UTF-8-BOM，Excel 直接開）：`鄉鎮市區, 地段名稱, 地號, 段代碼, 地號8碼, 查詢狀態,
國土功能分區, 原使用分區, 原使用地, 使用地, 備註`

`查詢狀態`：`有資料` / `查無`（都計區或清冊未登載，正常）/ `失敗`（段代碼對不到、格式錯、連線問題）/ `未查`。

跑完 stderr 印狀態與分區分布摘要，**這份摘要就是交付數字的來源**（勿另行估算）。

### `使用地` 欄常常是空的（實測）
官田案 145 筆**全部**回空白 —— 報部版草案階段尚未指定新編定使用地。**空白是正常狀態，
不是查詢失敗**，簡報寫「使用地編定待公告」而非留白或猜測。有值時才寫入。

### 必做的交叉核對
nluz 的 `原使用分區`/`原使用地` 對上清冊（或②join 後）的 `使用分區`/`使用地類別`：
```python
pd.crosstab(m['原使用地'], m['使用地類別'], margins=True)   # 對角線以外=不一致
```
官田案實測 **0 筆不符**（15 林業用地 + 130 農牧用地 完全吻合）——這是這份資料可信的證據。
有不符就要在簡報標註，可能是清冊版本差異，**不可自行選一邊當真**。

## 分區代碼對照（平台 legend，共 20 類）

| 碼 | 名稱 | 碼 | 名稱 |
|---|---|---|---|
| A10~A50 | 農業發展地區第一~五類（`A4T`=第四類(原)）| C10~C40 | 國土保育地區第一~四類 |
| M11/M12/M13 | 海洋資源地區第一類之一/之二/之三 | M20/M30 | 海洋資源地區第二/三類 |
| U10 | 城鄉發展地區第一類 | U21/U22/U23 | 城鄉發展地區第二類之一/之二/之三 |
| U30 | 城鄉發展地區第三類 | | |

平台回傳的是**中文全名**（如「農業發展地區第二類」），非代碼。

## 技術要點（實測傷痕，勿「優化」）

- **必須帶瀏覽器 User-Agent**，否則 `ex_data` 一律 404（不是路徑錯）。
- token 寫在 `default.aspx` 的 HTML 裡（`const layerToken = '...'`），綁 session＋需 `Referer`。
- SSL 憑證有問題 → `verify=False`（唯讀公開圖資）。
- `SEARCHCADA` 的 `VAL1` **必須是段代碼**（`DF4342`），給段名回「沒有符合條件的地籍資料」。
- `STATUS`：`1`=有資料、`0`=查無、`9`=限流（**唯一允許重試**，等 11s 再試）。
- 段代碼格式與 TCDGIS `SECTOR_SKINDA3` value 完全相同 → 可與 `tcdgis-parcels-to-shp` 共用。

## 拿不到的東西（別浪費時間試）

**國土功能分區的向量面本體拿不到。** `Exhibition_NLU_` 的子圖層 `query`/`identify`/`export`
全被 `ex3smap/mapproxy` 白名單擋（400），直連 REST 則 token 對該服務無權限。
只放行 `MapServer?f=json` 與 `/legend`。要面圖層仍走產線既有的本機 `國土功能分區/` 圖資。
（可取得的另有各縣市**分區圖範圍外框** `Exhibition_NLURange`，1 筆/縣市、原生 EPSG:3826。）

## 全國適用

服務含**全 22 縣市**圖層（layer 0~21，臺南=8）。`--county` 換縣市名即可，段代碼字首隨縣市改變
（臺南 D…），腳本會自動從平台取該縣市段清單，不需自行維護對照表。

## 用查詢結果出圖（套產線既有 QML，已實測）

CSV 沒有幾何 → **必須先 join 回基地圖層**，且**欄位要改名成 `zone`**——
`styles/國土功能分區.qml` 是 `attr="zone"` 的分類渲染，21 個類別值就是**中文全名**
（`農業發展地區第二類` 等），與 nluz 回傳值**完全一致**，改名後直接命中官方色，不必改樣式。

```python
base = gpd.read_file(r'<案>\圖層_讀取_基地.gpkg', layer='基地')
d    = pd.read_csv(r'<案>\國土功能分區.csv', encoding='utf-8-sig', dtype=str)
g    = base.merge(d[['地號','國土功能分區','原使用分區','原使用地','使用地','查詢狀態']],
                  on='地號', how='left')
g['zone'] = g['國土功能分區']          # ★ QML 認 zone,不改名不會上色
g.to_file(r'<案>\國土功能分區_逐筆nluz.gpkg', driver='GPKG', layer='國土功能分區_逐筆')
```
出圖用 QGIS python：`lyr.loadNamedStyle(r'<專案>\styles\國土功能分區.qml')`
（官田案實測 145/145 join、樣式 100% 命中、`classAttribute='zone'`）。

**與產線既有圖層的差異**：`國土功能分區/<縣市>…/*.shp` 是**面圖層**（全域、可直接出圖，
但版本各縣市不一）；本 skill 產出的是**逐筆宗地屬性**（權威報部版、與清冊 1:1 對得上）。
兩者互補：面圖層畫周邊底圖，逐筆結果標基地認定值與交叉核對。
